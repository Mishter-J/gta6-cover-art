Vice Cover Studio — a GTA-style cover art maker. Upload your own photos, arrange them in a multi-panel poster, write a bold caption, pick a Vice City sunset or neon colour grade, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Fully offline, no Rockstar artwork, logos or fonts: the lettering is Anton and Pacifico (SIL Open Font License), and the sample photos are AI-generated originals.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
