Vice Cover Studio — a GTA-style cover art maker. Upload your own photos, crop and position each one across a multi-panel poster layout, pick a sunset or neon colour grade, write a bold caption, and export the cover as a PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs offline in the browser: photos never leave your machine, fonts ship under app/fonts/ (SIL Open Font License), and there is no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server and open `index.html`.
